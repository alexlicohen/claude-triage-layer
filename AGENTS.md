# claude-triage-layer — working rules

- **One green gate:** `make verify` (lint+shellcheck → drift → 11 test suites: roundtrip 191, usage 25, ext-run 229, patch-check 44, stage-worktree 54, review-stage 61, workflow-scenarios 369, compare-scenarios 339, parity-suite 114, parity-scenarios 125, parity-report 204). Run it before accepting any change; never assert green without its output. `make mutate` runs the strict 160-mutation teeth check (~40 min: too long for triage-exec's check runner, run it directly) (any survivor fails) — it's also a CI step.
- **Danger zone:** `workflows/triage-exec.js` (executes the rubric; the external vendor (codex only; agy retired 2026-09-24) is chosen at plan time, plus inline bake-off challengers triage-exec picks from `config/tiers.json` tuning; `danger` work runs only on the Claude Opus/Fable families or codex gpt-6-astra (`DANGER_FAMILIES`), codex at effort ≥ high and level ≥ deep; Workflow-DSL constraints: `meta` stays a pure literal, no `Date.now`/`Math.random`/argless `new Date()`), `workflows/triage-compare.js`, `install.sh`, `uninstall.sh`, `scripts/ext-run.sh` (single owner of every codex invocation: success gate, deny-list — `review-stage.sh` asks it via `deny-query` —, the sandbox-exec confinement profile, worktree staging, command audit log; the threat model is accidents, not a hostile model) and `scripts/patch-check.sh` (the only grader of compare/parity patches). Changes here need `test/workflow-scenarios.mjs` / round-trip coverage, not just eyeballs.
- **Syncing to the live install:** `make sync` (= `install.sh --files-only`) — never hand-`cp` into `~/.claude`, bare `install.sh` is safe on a customized machine since Wave 9 (it no longer touches `model`/`effortLevel`/`statusLine`, and since Wave 12 skips `.driftignore` forks in every mode; it only adds `env.CLAUDE_CODE_SUBAGENT_MODEL` (= `config/tiers.json` levels.deep.claude.model, with its ownership marker `env.TRIAGE_LAYER_OWNS_SUBAGENT_MODEL`)/`subagentPromptCacheTtl` when unset, and upgrades the model only while it equals the marker or a frozen pre-marker default in `LEGACY_SUBAGENT_MODELS`; uninstall removes it only while it equals the marker and moves any non-repo bytes and agent memory to `triage-uninstall-backup-<ts>/`, never deletes them; `make sync` never touches settings — drift warns "settings migration pending"). Files listed in `.driftignore` are deliberate personal forks (currently `triage.md`) — sync skips them; drift reports them as `forked (expected)`.
- **Single owners:** every model id and Claude agent model/effort lives in `config/tiers.json` (Claude models as pinned concrete ids; bare aliases only in its `aliasHistory`, resolved by `model_id` in `scripts/parity-report.sh`) (`make tiers` rewrites agent frontmatter; lint fails on drift) — never hard-code one elsewhere; per-agent tally math lives in `scripts/triage-usage.sh` (stats/statusline consume it, never re-derive); in `triage-exec.js`, verdict parsing lives in `assess()`, the entry-contract validation in `bad()`/the top-of-file arg checks, the budget spawn decision in `spawn()`, the reviewer's presence in `reviewWanted()`, the escalation step in `redoStep()`, every Fable spawn in `runFable()`, and the returned distillate in `report()`, the danger floor by model family in `DANGER_FAMILIES` (lint checks tiers.json levels.deep/top against it); the expected-fork list is `.driftignore`; in `install.sh` the shipped-file checksum lists (`SHIPPED_TRIAGE_RUN_SHA256`, `SHIPPED_AGY_RUN_SHA256`, `SHIPPED_OVERFLOW_AGENT_SHA256`), retire decisions in `retire_renamed()`, backups in `backup_path()`/`prune_backups()`, the subagent-model decision in `sub_model_action()`; in `parity-report.sh` the ledger lock in `lock_ledger()` and the idempotence/collision decision in `commit_lines()`.
- **Tests must have teeth:** new guards get a mutation in `qc/mutate.sh`'s catalog plus a covering test. Anchors in the catalog are content-based — refresh them when refactoring an anchored region.
- **CHANGELOG.md by wave**, with commit hashes, check-count deltas, and honest deferred-items lists.
- **Direct pushes to `main` are blocked** by the local permission mode — merge via PR (`gh pr create` + `gh pr merge`).
