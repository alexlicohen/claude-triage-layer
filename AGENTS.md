# claude-triage-layer — working rules

- **One green gate:** `make verify` (lint+shellcheck → drift → 11 test suites: roundtrip 161, usage 25, ext-run 220, patch-check 38, stage-worktree 41, review-stage 53, workflow-scenarios 334, compare-scenarios 304, parity-suite 100, parity-scenarios 120, parity-report 123). Run it before accepting any change; never assert green without its output. `make mutate` runs the strict 85-mutation teeth check (~16 min: too long for triage-exec's check runner, run it directly) (any survivor fails) — it's also a CI step.
- **Danger zone:** `workflows/triage-exec.js` (executes the rubric; the external vendor (codex only; agy retired 2026-09-24) is plan-time only and takes `danger` work only with effort ≥ high at level ≥ deep; Workflow-DSL constraints: `meta` stays a pure literal, no `Date.now`/`Math.random`/argless `new Date()`), `workflows/triage-compare.js`, `install.sh`, `uninstall.sh`, `scripts/ext-run.sh` (single owner of every codex invocation: success gate, deny-list, the sandbox-exec confinement profile, worktree staging, command audit log) and `scripts/patch-check.sh` (the only grader of compare/parity patches). Changes here need `test/workflow-scenarios.mjs` / round-trip coverage, not just eyeballs.
- **Syncing to the live install:** `make sync` (= `install.sh --files-only`) — never hand-`cp` into `~/.claude`, bare `install.sh` is safe on a customized machine since Wave 9 (it no longer touches `model`/`effortLevel`/`statusLine`, and since Wave 12 skips `.driftignore` forks in every mode; it only adds `env.CLAUDE_CODE_SUBAGENT_MODEL`/`subagentPromptCacheTtl` when unset, or upgrades a previous installer default listed in `LEGACY_SUBAGENT_MODELS`). Files listed in `.driftignore` are deliberate personal forks (currently `triage.md`) — sync skips them; drift reports them as `forked (expected)`.
- **Single owners:** every model id and Claude agent model/effort lives in `config/tiers.json` (Claude models as pinned concrete ids; bare aliases only in its `aliasHistory`, resolved by `model_id` in `scripts/parity-report.sh`) (`make tiers` rewrites agent frontmatter; lint fails on drift) — never hard-code one elsewhere; per-agent tally math lives in `scripts/triage-usage.sh` (stats/statusline consume it, never re-derive); in `triage-exec.js`, verdict parsing lives in `assess()`, the entry-contract validation in `bad()`/the top-of-file arg checks, the budget spawn decision in `spawn()`, the reviewer's presence in `reviewWanted()`, the escalation step in `redoStep()`, every Fable spawn in `runFable()`, and the returned distillate in `report()`; the expected-fork list is `.driftignore`; the shipped-`triage-run.js` checksum list is `SHIPPED_TRIAGE_RUN_SHA256` in `install.sh`.
- **Tests must have teeth:** new guards get a mutation in `qc/mutate.sh`'s catalog plus a covering test. Anchors in the catalog are content-based — refresh them when refactoring an anchored region.
- **CHANGELOG.md by wave**, with commit hashes, check-count deltas, and honest deferred-items lists.
- **Direct pushes to `main` are blocked** by the local permission mode — merge via PR (`gh pr create` + `gh pr merge`).
